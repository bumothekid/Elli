# 🤖 Elli Discord Bot

Elli is a Discord bot built with Python and the Nextcord library. It is designed to provide useful features to enhance your Discord server experience.

## 🌟 Features

* **Welcome messages:** Send a welcome message with image to new members.
* **Goodbye messages:** Send a goodbye message with image to members who leave.
* **Auto-role:** Assign a role to new members.
* **Giveaway system:** Create giveaways with a simple command.
* **Leveling system:** Track user levels and experience.
* **Ticket system:** Create tickets for users to contact staff.
* **Moderation commands:** Kick, ban, mute, and more.
* **Temporary voice channels:** Create temporary voice channels.
* **Reaction roles:** Create reaction roles.
* **Invite tracking:** Track invites and see who invited who.

## ⚙️ Usage

To use Elli, invite the bot to your Discord server and use the various commands to customize your server experience.

For a full list of commands, type `-help` in your Discord server.
